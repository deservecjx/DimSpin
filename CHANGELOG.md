# Changelog

All notable changes to this project will be documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-19

### Added

- Initial project skeleton under the DimSpin name: MIT license, packaging
  metadata, tests and CI workflow.
- Numerical foundation: spin operators, tensor helpers, rotation/Euler
  utilities, line broadening (direct and FFT), powder orientation sampling,
  and parallel helpers.
- Hamiltonian terms: electron Zeeman, zero-field splitting, hyperfine,
  high-order Stevens operators and electric-field modulation through the
  T, R and F tensors.
- Resonance search: `High_Field_Method`, `Adaptive_Grid_Method` and an
  independent generalized-eigenvalue reference.
- Space-group expansion with data generated by spglib.
- Simulation pipeline (`Spin`, `Spec`, `autosim`), powder and rotation
  modes, plotting helpers and energy-level plots.
- Public API, five runnable examples, Sphinx documentation and CI checks for
  tests, coverage, packaging and the documentation build.

### Notes

- `Fused_Method` is not included in this release.
